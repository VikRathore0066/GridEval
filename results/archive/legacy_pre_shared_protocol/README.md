# Archived pre-protocol experiment outputs

These JSON files were generated on 2026-09-09, before the shared 24-observation rolling evaluation protocol was enforced. The baseline and calibration summaries include Prophet and a 19-quantile configuration that are not part of the current benchmark. The context sweeps use the prior evaluation run and are not validated for current paper claims.

They are retained only for provenance. Current dashboard tables and regenerated result tables must use the active files under `results/ercot/` and `results/gefcom/`. Do not restore these files to active paths or use them as current benchmark results.
